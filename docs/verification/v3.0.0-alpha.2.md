## Merge blocker: JavaScript depth preflight (resolved in follow-up)

In [js_ast.cjs](../../skills/sentinel-shield/scanner/js_ast.cjs), `preflight` calls `ts.forEachChild(node,ch=>todo.push([ch,depth+1]))`. Array.push returns the new array length; TypeScript stops visiting siblings when the callback returns a truthy value. A deep second statement can therefore bypass the intended 200-level preflight limit.

Reproduction: parse a TypeScript file containing `const shallow = 1;` followed by `const deep = `, 210 opening parentheses, `x`, 210 closing parentheses and a semicolon. With TypeScript 5.8.3, the package traversal visited 5 nodes and reached depth 4. A callback that returns nothing visited 222 nodes and reached depth 214. This demonstrates a bypass of the preflight check, not execution of target code.

Resolved by the follow-up patch. The traversal callback is now block-bodied, a named `BudgetError` is reported, and a 210-level second-statement regression verifies incomplete coverage. The package inventory and source-file SBOM were regenerated.

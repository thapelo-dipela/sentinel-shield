## Reproduce

With Docker available, check out the release and run this equivalent POSIX-shell command from the repository root. Docker may need network access to obtain the pinned image; the test container itself has no network. On Windows, use the absolute package path in the bind mount and PowerShell-appropriate line continuations.

```sh
git checkout v2.5.0
docker run --rm \
  --network none --read-only --cap-drop ALL \
  --security-opt no-new-privileges \
  --pids-limit 128 --memory 512m --user 65534:65534 \
  --tmpfs /tmp:rw,nosuid,nodev,size=128m \
  --mount "type=bind,source=$(pwd)/skills/sentinel-shield,target=/package,readonly" \
  -w /package \
  python@sha256:ae14d4ce8771606477a81446e7ef429edd6762305fc50c84507c1041fa8285d1 \
  sh -c 'python --version &&
    python -B -I scanner/verify_integrity.py --expected-manifest-sha256 6c35bab210f891174e4a938731b70fb3d4cf7b50608ed98386a23a8d03929b69 &&
    python -B -I -m unittest discover -s tests -v &&
    python -B -I scanner/verify_integrity.py --expected-manifest-sha256 6c35bab210f891174e4a938731b70fb3d4cf7b50608ed98386a23a8d03929b69'
```

## Scope

This run verifies the supplied regression suite and file inventory on one Linux/Python environment. Third-party scanner calls and feed downloads in the tests are mocked. It does not validate live Trivy/Semgrep/Gitleaks compatibility, current feed availability, real-world detection accuracy, or all supported Python versions.

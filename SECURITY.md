# Security policy

Use Sentinel Shield only for systems you own or are authorized to assess.

To report a vulnerability in Sentinel Shield, use GitHub's private vulnerability reporting under this repository's Security tab. Include affected versions, impact, and a minimal synthetic reproduction. Never publish live credentials, private code, or sensitive exploit details in a public issue.

The current published source is v2.5.0. No response-time or long-term support guarantee is made.

Scanner findings require human verification. Passing tests or receiving exit code 0 does not certify a repository as secure. See the package documentation for coverage and external-tool limitations.
